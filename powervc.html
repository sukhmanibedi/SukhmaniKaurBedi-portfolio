IBM PowerVC

IBM PowerVC is built on OpenStack, providing simplified virtualization management and cloud deployments for IBM AIX®, IBM i, and Linux virtual machines running on IBM® Power® servers. Designed to establish private cloud capabilities and optimize enterprise administrator productivity at scale.

Focus Group System Admins & Architects
Sector Cloud Management
Role UX Researcher & Lead Designer
Duration 23 months

Overview of the redesigned IBM PowerVC dashboard interface.

Project Overview

System administrators and technical users managing virtual machines (VMs) on IBM Power Systems via PowerVC face severe usability bottlenecks due to dense legacy UI layouts, complex navigation hierarchies, and insufficient contextual feedback. Performing routine operations—such as VM provisioning, host configuration, patch management, and large-scale system scaling—resulted in steep cognitive overhead, high error rates, and elongated task completion times when managing thousands of VMs and storage volumes.

As lead designer and researcher, I spearheaded the comprehensive UX overhaul of PowerVC. By implementing rigorous Enterprise Design Thinking methodologies, generative user studies, heuristic evaluations, and complexity analyses, we transformed the platform into a streamlined, intuitive enterprise management ecosystem.

Snippets of the Legacy UI

Legacy Home dashboard (left) and Networks page (right) displaying visual density, deep menus, and inconsistent status treatments.

Problem Statement

PowerVC users struggled with specific operational roadblocks:

  • Fragmented Workflows: Multi-step manual procedures required to execute standard VM creation and provisioning.
  • Interface Discrepancies: Disconnects between GUI interactions and underlying OpenStack API functionalities causing user confusion.
  • Bulk Management Friction: Inadequate multi-item operations when overseeing thousands of active virtual environments.
  • Opaque System Feedback: Lack of real-time status visibility during critical background operations, leaving administrators uncertain.

User Research & Methodology

Our research strategy combined generative customer partnerships, online user forum analysis, Net Promoter Score (NPS) tracking, and Request for Enhancement (RFE) categorizations to ensure a deeply user-backed redesign.

Deriving the Three Hills

Following IBM’s Enterprise Design Thinking framework, we established three primary Hill statements to focus our engineering and design execution:

“Alan, a system architect, can ensure his PowerVC UI is secure by applying updates on the fly without system interruption.”

“Monica, a system admin, can manage 10K VMs and 25K volumes using PowerVC, without experiencing performance lag.”

“Steve, a technical user, can request and provision a new VM in less than 1 minute.”
